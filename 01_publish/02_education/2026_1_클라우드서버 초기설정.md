# ssh 포트 설정
* 기본 22포트로 세팅이 되어있으나 접속이 안되는듯 하여 2222포트로 변경
```
apt update
```

```
apt install -y openssh-server
```

```
ufw allow 2222/tcp
```

```
sed -i 's/^#Port 22/Port 2222/' /etc/ssh/sshd_config
```

```
systemctl restart ssh
```

# 사용자 설정
* claude의 bypass는 root에서 실행할 수 없다
```
adduser 사용자이름
```

```
usermod -aG sudo 사용자이름
```
* 관리자 권한주기

```
! passwd 사용자이름
```
* 패스워드 설정하기

* bypass 설정
```
claude --dangerously-skip-permissions
```
* 일회 실행시 위 명령어로 실행하고 bypass 설정해달라고 하면 됨

```
다음에 이 클로드가 bypass로 실행될수 있도록 설정해줘
```
