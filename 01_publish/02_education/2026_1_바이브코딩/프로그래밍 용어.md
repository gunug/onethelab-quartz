# 프로그래밍 용어 (programming terms)

* 시리즈를 시작하려는 이유

# 용어의 의미를 모르고 사용
* API, 라이브러리


* ***API** = 다른 프로그램과 대화하는 규칙 세트. "OPEN API 호출해서 날씨 데이터 받음"

* ***라이브러리** = 미리 만든 코드 묶음을 가져다 쓰기. "React 라이브러리로 UI 만들고 있어"

# 용어 자체가 무엇인지 모름
* 멱등성

* ***멱등성(Idempotent)** = 같은 명령을 여러 번 해도 결과가 같음. 예: 체크박스 누르기, 결제 완료 버튼 누르기. "멱등성이 있는 API는 실패했을 때 재시도해도 안전함"

# AI가 뜻을 오해
