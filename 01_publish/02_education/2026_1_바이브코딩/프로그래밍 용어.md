# 프로그래밍 용어 (programming terms)

* 시리즈를 시작하려는 이유

# 용어의 의미를 모르고 사용
* API, 라이브러리


* ***API** = 다른 프로그램과 대화하는 규칙 세트. "OPEN API 호출해서 날씨 데이터 받음"

* ***라이브러리** = 미리 만든 코드 묶음을 가져다 쓰기. "React 라이브러리로 UI 만들고 있어"

# AI가 뜻을 오해
* 짧고 간결하게 할 수 있는 말을 풀어서 하게 되고 AI가 뜻을 오해

* ***"Ref"** (짧음) → AI가 "Reference(참조)" 전체를 설명해서 "데이터 구조에서 다른 메모리 위치를 가리키는..." 이렇게 길어짐
