# race condition
* 하나의 상태(condition)를 가지고 경쟁(race)이 붙는 상태
* 티켓을 획득 전까지는 두사람에게 모두 티켓이 있는것으로 보이지만 한명이 획득하면 티켓이 사라짐

# partial write
* 쓰는 도중 유실되는 상태

# Atomic operation
* race condition을 해결
* 한번에 조회부터 요청까지 다 하는것, 조회 실패시 요청되지도 않음
