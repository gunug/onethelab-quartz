* **Development(개발)**와 **Operations(운영)**를 합친 용*
* 원래는 개발팀과 운영팀이 분리되어 있었는데, DevOps는 **개발부터 배포, 운영, 모니터링까지 하나의 흐름으로 관리하는 문화와 방법론**을 의미합니다.

### DevOps에서 자주 하는 일

- 서버(VPS, 클라우드 서버) 생성
- Docker 설치
- Docker Compose 또는 Dokploy 설정
- GitHub 저장소 연결
- CI/CD 구축
- SSL 인증서 적용
- 도메인 연결
- 모니터링 및 로그 확인
- 백업 자동화

즉, **"애플리케이션이 실제 서비스되기 위한 모든 과정"**을 다룹니다.
