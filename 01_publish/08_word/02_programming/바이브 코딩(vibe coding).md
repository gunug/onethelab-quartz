* **바이브 코딩(Vibe Coding)**은 사람이 코드를 직접 한 줄씩 작성하기보다, **자연어로 원하는 기능을 설명하면 AI가 코드를 생성하고 수정하는 개발 방식**을 말합니다. 이 용어는 2025년 초 AI 연구자들이 사용하면서 널리 알려졌습니다.

- 개발자들은 **"바이브 디버깅이나 하면서 놀자"**라고 생각하고 있고,
- 상사는 **"새 앱 하나 만들어줘!"**라며 기대하고,
- AI는 **"물론이죠! 무엇을 도와드릴까요?"**라고 즉시 응답합니다.

즉, **AI가 개발을 엄청나게 쉽게 만들어 줄 것이라는 기대와, 실제 개발 현장의 현실 사이의 간극**을 유머러스하게 표현한 만화입니다. 이는 바이브 코딩을 무조건 찬양하거나 비판하기보다는, 현재 업계의 과도한 기대를 풍자하는 성격이 강합니다.
