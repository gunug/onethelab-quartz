# MonsGeek 키보드 Fn(펑션) 키 단축키

> **참고:** 모델(M1, M1W, M3, FUN60, MG75 등)에 따라 일부 기능이 다를 수 있습니다.

## 일반 기능

| 단축키 | 기능 |
|--------|------|
| `Fn + F1` | 내 컴퓨터 |
| `Fn + F2` | 이메일 |
| `Fn + F3` | Windows 검색 |
| `Fn + F4` | 웹 브라우저 홈 |
| `Fn + F5` | 미디어 플레이어 |
| `Fn + F6` | 재생 / 일시정지 |
| `Fn + F7` | 이전 곡 |
| `Fn + F8` | 다음 곡 |
| `Fn + M` | 음소거 |
| `Fn + <` | 볼륨 감소 |
| `Fn + >` | 볼륨 증가 |
| `Fn + P` | Print Screen |
| `Fn + C` | 계산기 |
| `Fn + I` | Insert |
| `Fn + W` | WASD ↔ 방향키 전환 |
| `Fn + Win` | Windows 키 잠금 |

## RGB 기능

| 단축키 | 기능 |
|--------|------|
| `Fn + L` | RGB 켜기 / 끄기 |
| `Fn + ↑` | 밝기 증가 |
| `Fn + ↓` | 밝기 감소 |
| `Fn + ←` | 효과 방향 변경 |
| `Fn + →` | 효과 방향 변경 |
| `Fn + -` | 효과 속도 감소 |
| `Fn + =` | 효과 속도 증가 |
| `Fn + Home` | RGB 효과 변경 |
| `Fn + PgUp` | RGB 효과 변경 |
| `Fn + End` | RGB 효과 변경 |
| `Fn + PgDn` | RGB 효과 변경 |
| `Fn + \` | 단색 7가지 순환 |

## 무선 모델 전용

| 단축키 | 기능 |
|--------|------|
| `Fn + E` | Bluetooth 1 |
| `Fn + R` | Bluetooth 2 |
| `Fn + T` | Bluetooth 3 |
| `Fn + E/R/T` (3초) | Bluetooth 페어링 |
| `Fn + Y` | 2.4GHz 모드 |
| `Fn + U` | 유선 모드 |

## 기타

| 단축키 | 기능 |
|--------|------|
| `Fn + Space` | 배터리 잔량 표시 (지원 모델) |
| `Fn + O` (3초) | Windows / Mac 모드 전환 (지원 모델) |
