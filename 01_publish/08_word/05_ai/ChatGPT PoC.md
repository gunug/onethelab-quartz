PRE(Problem · Requirement · Evaluation)

# PoC
- **PRE (Problem · Requirement · Evaluation)**
    - 문제 정의
    - 검증 목표 정의
    - 성공 기준 정의
- **EXP (Experiment)** ← 다음 단계
    - 무엇을 만들 것인가?
    - 어떤 방식으로 검증할 것인가?
    - 어떤 데이터와 기술을 사용할 것인가?
    - 어떤 결과를 수집할 것인가?
- **BUILD**
    - 최소 기능 구현
    - 실험 수행
- **REVIEW**
    - 성공 기준과 비교
    - 실패 원인 분석
    - 다음 PoC 또는 제품화 여부 결정

---

- **웹 서비스 PoC**: 간단한 HTML/CSS/JavaScript, React, Next.js 생성
- **백엔드 PoC**: API 서버, 데이터베이스 연동 예제 작성
- **AI PoC**: LLM, 이미지 생성, 음성인식 등을 연결한 데모 제작
- **업무 자동화 PoC**: Gmail, Drive, Slack, Notion 등을 연동하는 워크플로 설계
- **앱 PoC**: Flutter, React Native, Android 앱의 동작 가능한 시제품 생성

---

또한 ChatGPT에는 다음과 같은 기능들이 PoC 제작을 돕습니다.

- **Canvas**: 여러 파일을 포함한 프로젝트를 함께 수정하며 개발
- **코드 실행(Python)**: 데이터 분석, 알고리즘 검증, 그래프 생성
- **웹 검색**: API 문서나 최신 정보 확인
- **이미지 생성**: UI 목업, 아이콘, 시안 제작
- **파일 업로드**: 요구사항 문서나 API 명세를 기반으로 구현

즉, **'PoC 모드'는 없지만, ChatGPT 자체를 PoC 개발 도구처럼 사용할 수 있습니다.**
